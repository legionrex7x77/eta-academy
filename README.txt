ITA ACADEMY — SITIO PARA HOSTINGER

1. Cambia el número 5210000000000 del enlace de WhatsApp en index.html.
2. Modifica nombre, precios, dirección y textos directamente en index.html.
3. En Hostinger abre Administrador de archivos > public_html.
4. Sube index.html, styles.css, script.js y la carpeta assets.
5. Verifica que index.html quede directamente dentro de public_html.

No necesita Python, base de datos ni instalación de paquetes.
